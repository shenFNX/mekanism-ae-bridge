# 任务缓存与样板隔离

这些机器采用 GTNH 风格的预投递：只要没有超过配置的任务缓存上限，AE2 合成 CPU 可以一次把大量完整操作发进机器。并行升级只决定缓存的任务加工多快，不决定 AE2 可以预先发配多少。

每个已接受任务都会按编码样板身份和精确的输入/输出比例单独记账。即使两个配方使用同一种物品并搭配不同化学品，它们的材料也不会进入同一个加工账本。

只要当前任务还有完整材料，机器就会继续加工当前样板。当前任务无法继续且已完成产物处理完毕后，才会切换到其他等待样板，因此不会在多个配方之间反复轮换。

返还按钮会尝试把缓存输入、完成产物和等待资源全部插回 ME 存储。如果网络无法接收全部资源，剩余部分会继续保留在机器中，并进入保护状态，不会被删除。
