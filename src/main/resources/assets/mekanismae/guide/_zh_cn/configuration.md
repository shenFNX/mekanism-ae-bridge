# 配置

可以打开模组配置界面，也可以编辑 `config/mekanismae-server.toml`。如果某个存档需要独立数值，把该文件复制到 `saves/<存档>/serverconfig/mekanismae-server.toml` 后修改副本；没有存档副本时会使用全局文件。

可配置内容包括：

* 是否消耗 AE2 频道、待机 AE 功耗和红石暂停行为。
* FE 容量、最大 FE 输入、每次操作耗能和加工时间。
* 最大预投递操作数，以及每台机器独立的每周期基础处理份数。
* 0～8 张速度卡和并行卡的完整倍率曲线。
* 基础、高级、精英、终极等级对并行、能量容量、FE 输入和缓存容量的倍率。
* 全机器公共默认值，以及各机器可选的能量、时间和缓存覆盖值。

配置在重新载入世界后生效。降低缓存上限不会删除已经接收的工作；机器只会停止接收新任务，直到占用量回到新上限以下。降低能量容量时，超出新容量的已存能量会被截断。
