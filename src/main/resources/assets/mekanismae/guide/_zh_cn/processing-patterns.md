# 处理样板

顶部 27 个槽只接受已编码的处理样板。机器只会向 AE2 发布属于自身 Mekanism 配方类型的样板。

已连接且空闲的机器会显示在 AE2 样板管理终端中，27 个槽位按机器名称和图标分组。机器接收加工任务后会暂时从终端隐藏，因为隔离任务账本处理完毕或安全返还前，样板必须保持锁定。

有效样板需要满足：

* 输入必须组成一次或多次完整配方操作。
* 所有输入数量必须使用相同的整数倍率。
* 写进样板的每一种产物，其数量都必须与该倍率下的真实配方一致。
* 资源方向必须与机器相符，例如物品转化学品，或流体转两种化学品。

样板可以整体放大很大的整数倍。27 个实体样板槽并不代表一次合成最多只能发配 27 份；机器会把已接受的工作保存在内部缓存中。

JEI 显示的 Mekanism 配方数量是基准。速度和并行升级不会改变配方材料用量。对于 Mekanism 以每 tick 消耗表示的化学品配方，本模组会把每次操作的总用量固定为配方所表达的总量。
