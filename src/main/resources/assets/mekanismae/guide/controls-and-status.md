# Controls and Status

## Left Tabs

* **ME tab:** shows whether the network is online. Click it to enable or disable the machine's network participation.
* **Return tab:** returns internal processing resources to ME storage without removing installed patterns or upgrades.
* **Energy tab:** shows stored FE, capacity, and the maximum accepted FE/t.

## Machine Panel

The top row contains nine processing-pattern slots. The upper-left slot holds one Mekanism tier installer. The right drawer contains Speed, Parallel, and Energy Cards. The center display shows status, buffered operations, energy, current resources, progress, and the player-facing parallel multiplier.

The question-mark button opens this guide. GuideME's configurable guide hotkey can also open it directly.

With Jade installed, the block tooltip reports network state, task buffer, active resources, fault state, speed and player-facing parallel values, and exact energy.

An idle machine can be broken normally. Installed patterns, cards, and the tier installer drop as items. A machine with active, queued, or pending-return processing resources refuses to break until the work is completed or returned safely.
