# Mekanism ME Integration

Mekanism ME Integration 是一款面向 Minecraft 1.21.1 NeoForge 的自动化模组，让 Mekanism 加工机器直接成为 AE2 处理样板提供器。无需再为每台机器搭建复杂的外部输入、输出与回收线路，样板、材料、流体、化学品和产物都可以在同一个 ME 网络中完成调度。

模组目前提供 19 台 ME 化 Mekanism 机器，并带有 9 个样板槽、GTNH 风格的大容量预投递缓存、严格的样板隔离、连续配方加工、物品/流体/化学品统一账本，以及速度、并行、能量卡和 Mekanism 等级安装器。GuideME、JEI、AE2 JEI Integration 与 Jade 兼容让指南阅读、配方录入和状态检查保持直观，同时完整配置系统允许普通玩家与整合包作者调整吞吐、能耗、缓存和升级倍率。
